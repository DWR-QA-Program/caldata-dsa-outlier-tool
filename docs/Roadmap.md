## Roadmap

This roadmap includes recommendations on how to continue to develop the tool in this Github repository to best suit DWR's changing needs.

### Integrating with Aquarius
This section will include recommendations on how to incorporate the Aquarius API into the tool.

### Transitioning to a fully automatic pipeline
This section will include recommendations on how to transition from our current outlier detection approach, which requires a human in the loop, to a fully automatic approach. Transitioning to a fully automatic pipeline requires change management at DWR.

### Including machine learning methods
This section will include recommendations on how to integrate machine learning methods for outlier detection into the tool, together with the data and infrastructure requirements to do so. We will also include a prototype approach, developed with a synthetic training dataset.

### Developing additional features
This section will include a prioritized list of recommendations on how to further develop the tool, identified from two rounds of usability testing.
